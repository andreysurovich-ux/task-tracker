# Task Tracker

Учебный список задач: добавление, статусы, приоритеты, фильтры.

Сайт: https://andreysurovich-ux.github.io/task-tracker/

## Где хранятся данные

Задачи хранятся в базе Supabase (проект `task-tracker`, таблица `tasks`).
Если в браузере остались задачи из старой версии (localStorage), после входа они переносятся в базу.

## Вход и правила доступа

- Вход по почте и паролю (Supabase Auth). Пользователь один — владелец. Регистрация новых пользователей выключена.
- Включена защита строк (Row Level Security). Без входа задачи не видны и не меняются.
- Читать, добавлять, менять и удалять задачи может только учётная запись владельца.
- В коде лежат только адрес проекта и публичный (publishable) ключ. Секретные ключи и пароли в репозиторий не попадают.
