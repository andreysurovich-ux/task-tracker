# Task Tracker

Учебный список задач: добавление, статусы, приоритеты, фильтры.

Сайт: https://andreysurovich-ux.github.io/task-tracker/

## Где хранятся данные

Задачи хранятся в общей базе Supabase (проект `task-tracker`, таблица `tasks`). Все, кто открывает сайт, видят один и тот же список.
Если в браузере остались задачи из старой версии (localStorage), при первом открытии они переносятся в базу.

## Правила доступа

- Включена защита строк (Row Level Security).
- Анонимный пользователь может читать, добавлять, менять и удалять задачи только в таблице `tasks`. Больше ничего не открыто.
- Входа в приложение нет, поэтому **любой, у кого есть ссылка, может менять задачи**. Храните здесь только тестовые данные.
- В коде лежат только адрес проекта и публичный (publishable) ключ. Секретные ключи в репозиторий не попадают.

## Файлы

- `style.css` — внешний вид
