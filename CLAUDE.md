# Правила работы над Task Tracker

- Работать маленькими этапами. После каждого этапа ждать, пока пользователь проверит результат.
- Менять только то, о чём просят. Ничего не переделывать «заодно».
- Технологии: обычные HTML, CSS и JavaScript (index.html, style.css, app.js). Без React, без базы данных, без внешних сервисов и скриптов из интернета.
- Задачи хранятся только в браузере (localStorage).
- Никогда не записывать в код секретные ключи, пароли и токены.
- Объяснять простыми словами: пользователь не программист.

## Сохранение на GitHub

- После новой функции или заметного блока работы сохранять версию (commit) и отправлять её на GitHub (push), чтобы там всегда была свежая рабочая версия.
- Не сохранять после каждой мелкой правки вроде смены цвета или текста — такие правки входят в следующую версию.
- Перед отправкой коротко говорить, что вошло в версию.
- Не отправлять секретные и лишние файлы.
